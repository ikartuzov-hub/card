
## Ссылки — одна точка правки

Все внешние адреса визитки живут в `links.json`. В страницах и в `igor-kartuzov.vcf`
ссылки **руками не правятся никогда** — иначе разъедутся шесть страниц и vCard,
которая оседает в телефонных книжках контактов навсегда.

Порядок смены адреса:

1. В `links.json` у нужного ключа: прежнее значение перенести в `aliases`,
   новое записать в `url`.
2. `python3 tools/sync-links.py` — сухой прогон, показывает что и где изменится.
3. `python3 tools/sync-links.py --apply` — применить.
4. Проверить одну страницу глазами, закоммитить.

Проверка «всё ли синхронно» — просто запуск без `--apply`.
